NJ BLACK CROW — الموقع (v4: درون فوق الموصل)

التشغيل:
  الموقع يحتاج سيرفر (ما يشتغل اذا فتحت index.html مباشرة من الملفات).
  أسهل طريقة: افتح app.netlify.com/drop واسحب هذا المجلد كله عليه.
  على الكمبيوتر: داخل المجلد شغّل  python -m http.server  وافتح localhost:8000

التعديل:
  المشاريع: أول ملف app.js (قائمة PROJECTS).
  النبذة والنصوص: index.html.
  الألوان: أول ملف styles.css.
  مواقع المعالم ومجرى دجلة: js/geo.js (خطوط طول وعرض حقيقية، 1 وحدة = 8 متر).
  شكل المعالم (كل معلم بملفه، الوحدة متر):
    js/hadba.js   منارة الحدباء (مسح القياسات + الصور)
    js/nuri.js    مصلى جامع النوري وصحنه
    js/bridge.js  الجسر العتيق والجسر الموازي
    js/grand.js   جامع الموصل الكبير (المسقط بـ js/grand_plan.js من OSM + القمر الصناعي)
    js/platform.js منصة الاحتفالات (المدرّجات والشلال والمنصة الرسمية)
    js/yunus.js   جامع النبي يونس 2026 (التل بمدرّجاته الستة)
  مسار الدرون لكل محطة: app.js (قائمة ST).

المحطات بالترتيب:
  سما الموصل ← الجسر العتيق (عنّي) ← جامع الموصل الكبير (المشاريع)
  ← منصة الاحتفالات (السلسلة) ← جامع النبي يونس (الغنائم) ← منارة الحدباء (القناة)

المكونات (كلها محلية، بدون اعتماد على مواقع خارجية):
  three.js r186 (مع Water.js للانعكاسات) و GSAP 3.15 و Matter.js داخل vendor
  الخطوط IBM Plex Sans Arabic و JetBrains Mono داخل fonts (رخصة OFL)
  السرب مبني على مثال three.js الرسمي webgl_gpgpu_birds (MIT)

مصادر البيانات الحقيقية:
  الشوارع والمساحات والمي: OpenStreetMap (مع مضلع نهر دجلة الكامل)
  البنايات: Overture Maps (OSM + Microsoft ML Buildings) ~116 ألف بناية بمواقعها الحقيقية
  التضاريس: Copernicus GLO-30 (30م) ومجرى دجلة محفور بيها
  المعالم: صور ويكيميديا والأخبار (2024-2026) + صور الأقمار الصناعية للمساقط والمواقع

وضع الجهاز الضعيف (اختياري):
  الافتراضي = جودة كاملة. اذا جهازك بدون كرت شاشة حقيقي (llvmpipe/SwiftShader) وتقبل تنزّل الجودة،
  افتح  localhost:8000/#lite  (يخفّض الدقة ويطفي الـ bloom ويقلل تحديث انعكاس الماء).
